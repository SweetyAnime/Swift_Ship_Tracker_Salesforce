# TNSkills Salesforce – SwiftShip Tracker

## 📦 Project Overview

**SwiftShip Tracker** is a Salesforce-based parcel management and tracking solution developed as part of the **TNSkills Salesforce** project.

The project uses Salesforce CRM, Flows, Prompt Builder, Agentforce, custom objects, security controls, and automation to provide a centralized platform for managing parcel bookings, tracking, delivery information, and customer support.

The project also integrates **Agentforce AI** to provide conversational parcel tracking and assistance.

## 🎯 Project Objectives

The main objectives of the project are:

- Build a centralized parcel management system using Salesforce.
- Manage parcel, sender, receiver, and delivery information.
- Automate parcel-related processes using Salesforce Flow.
- Provide real-time parcel tracking and status updates.
- Use Agentforce for conversational parcel tracking.
- Use Prompt Builder to retrieve and summarize parcel information.
- Implement role-based access and security controls.
- Provide reports and dashboards for monitoring parcel operations.
- Reduce manual effort for customers, agents, and administrators.

## 🗂️ Custom Objects

The project contains the following custom objects:

### Parcel

Used to store parcel information.

Important fields include:

- Parcel ID
- Status
- Weight
- Estimated Delivery Date
- Sender

### Delivery

Used to manage delivery-related information.

Important fields include:

- Current Location
- Estimated Delivery
- Sender
- Parcel

### Sender

Stores sender-related information such as:

- Sender Name
- Address
- Contact Number
- Email

### Receiver

Stores receiver-related information such as:

- Receiver Name
- Address
- Contact
- Email
